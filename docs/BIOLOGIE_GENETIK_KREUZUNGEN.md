## Rechenfälle und Papieralternative

Die sechs Kreuzungen ohne doppelte Elternreihenfolge haben folgende Genotypverteilungen:

| Kreuzung | AA | Aa | aa |
| --- | ---: | ---: | ---: |
| AA × AA | 100 % | 0 % | 0 % |
| AA × Aa | 50 % | 50 % | 0 % |
| AA × aa | 0 % | 100 % | 0 % |
| Aa × Aa | 25 % | 50 % | 25 % |
| Aa × aa | 0 % | 50 % | 50 % |
| aa × aa | 0 % | 0 % | 100 % |

Vertauschen der Eltern ändert diese Verteilungen im Modell nicht. Für A dominant werden AA und Aa dem roten Phänotyp zugeordnet; aa bleibt weiß. Bei der Zwischenform sind AA rot, Aa rosa und aa weiß. Die Papieralternative verlangt alle sechs Quadrate und Verteilungen sowie beide Farbzuordnungen. Die Vergleichslösung enthält sämtliche verlangten Werte und erläutert die unabhängige nächste Chance. Die übrigen Lösungen erklären die Strukturzeichnung, Wachstumsdaten, PKU-Kette und einen möglichen Belegplan für die Anwendungsentscheidung.
