Materialplaner

Für einen fiktiven Klassenworkshop erhält jede Gruppe dasselbe Materialpaket. Bestimme zuerst auf Papier den Bedarf für vier Gruppen. Vergleiche danach mit dem Programm und ändere eine eigene Dateikopie.

Nur ganze Gruppen. Null ist ein Testfall: Für keine Gruppe wird kein Material benötigt.

So wird aus dem Auftrag ein Programm

  1. Zerlegen: Bedarf pro Gruppe festlegen, Eingabe prüfen, jede Materialmenge berechnen, Ergebnis beschriften und testen.
  2. Muster erkennen: Für jede Materialart gilt dieselbe Rechnung: Gruppenanzahl mal Bedarf pro Gruppe.
  3. Abstrahieren: Für diese Mengenplanung brauchen wir Materialname, Einheit und Stückzahl pro Gruppe. Gruppennamen und Lieblingsfarben ändern die Rechnung nicht. Für eine andere Aufgabe könnten Farben wichtig sein.
  4. Algorithmus: Gehe die Materialliste durch. Berechne für jeden Eintrag den Gesamtbedarf. Gib Name, Menge und Einheit gemeinsam aus.

JavaScript lesen und verändern

Die eckigen Klammern in materialien begrenzen eine Liste. Jeder Eintrag in geschweiften Klammern enthält zusammengehörige Angaben. for…of besucht jeden Eintrag. * bedeutet Multiplikation; push hängt einen Eintrag an die Ergebnisliste an. return gibt das Ergebnis der Funktion zurück.

Die Menge pro Gruppe ist eine Vorgabe dieses Modells. Die Anwendung prüft keinen Lagerbestand und bestellt nichts. Sie arbeitet vollständig in dieser Datei, speichert keine Eingaben und benötigt kein Konto. Eine Papierlösung übt die Planung; zur Programmieraufgabe gehört auch das Ändern und Ausführen der Kopie.
